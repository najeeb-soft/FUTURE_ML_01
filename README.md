 Project Overview
This project focuses on building a Sales Forecasting System using historical business data. The goal is to help businesses plan inventory and manage resources by predicting future demand using Machine Learning.

Implementation Details
Data Cleaning: Handled missing values and prepared time-series data.
Feature Engineering:** Extracted features like `Year`, `Month`, `Day`, and `DayOfWeek` to capture seasonality.
Algorithm:** Used **Random Forest Regressor** to predict sales volume.
Evaluation:** Measured performance using Mean Absolute Error (MAE).

 Business Value
1. Inventory Management: Helps prevent overstocking and stockouts.
2. Staffing: Predicts high-volume days for better employee scheduling.
3. Cash Flow: Assists in financial planning based on expected revenue.
